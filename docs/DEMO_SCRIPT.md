# Veilance 데모 대본 (약 3분)

데모 주소: **https://lejuho.github.io/Veilance/?mode=demo** — 브라우저만 있으면 됩니다. 로그인은 시연 계정 버튼을 누르면 됩니다.

`?mode=demo` 없이 열면 먼저 발표자 PC의 라이브 노드에 연결을 시도하고, 응답이 없으면 **프론트 데모로 보기** 버튼을 보여 줍니다. 라이브 시연 방법은 아래 [라이브 시연 (Preprod)](#라이브-시연-preprod)에 있습니다.

> 이 주소는 **시뮬레이션 모드**입니다. 화면과 규칙은 실제 서비스와 같지만, 컨트랙트 규칙을 브라우저 안에서 흉내 내고 체인에는 기록하지 않습니다. 실제 Midnight 체인(로컬 데브넷 · Preprod)에서 같은 흐름이 동작하는 것은 저장소의 테스트와 문서로 확인됩니다. 영상 첫 장면이나 마지막에 이 점을 한 줄로 밝혀 주세요.

## 한 줄 소개

배터리 원자재 공급망의 **프라이버시 공유 원장**입니다. 재활용 물량이 여러 고객에게 **이중으로 주장되지 못하게** 막으면서, 물량·거래처 같은 영업비밀은 드러내지 않고 EU 배터리 규정이 요구하는 재활용 함량을 증명합니다.

## 촬영 전 준비

1. 데모 주소를 열고 상단 노란 띠의 **처음부터 다시**를 누릅니다.
2. 화면을 1280×800 정도로 맞춥니다. 한국어가 기본이고, 오른쪽 위에서 영어로 바꿀 수 있습니다.
3. 회사 전환은 오른쪽 위 **나가기** → 시연 계정 버튼으로 합니다.

## 강조할 세 가지

1. **이중 계상 사전 차단:** 한 번 쓴 로트와 재활용분은 어느 회사·플랫폼을 거쳐도 다시 쓸 수 없습니다(사용 식별자, nullifier).
2. **선택 공개:** 체인에는 커밋먼트·사용 식별자·암호문·신고 비율만 남습니다. 수량·재료·원산지·공급사·주문 수량은 받는 회사나 인증기관처럼 필요한 상대에게만 갑니다.
3. **규칙은 회로가 강제:** 수량 보존, 가공 수율 상한, 재활용 비율 상한, 초과 신고 거부는 Compact 회로가 영지식 증명으로 검증합니다.

## 문제가 생기면

- 화면이 꼬였으면 노란 띠의 **처음부터 다시**를 누르고 흐름 처음부터 다시 합니다.
- 거래 하나는 약 2초 걸립니다(시뮬레이션). 실제 체인에서는 30~70초입니다.

## 라이브 시연 (Preprod)

같은 Pages 화면이 발표자 PC의 실제 Preprod 노드와 통신합니다. 노드는 로컬에서 돌고, 터널로 HTTPS 주소를 받습니다.

1. Docker Desktop과 proof server(`127.0.0.1:6300`)를 켭니다.
2. `scripts/live-demo.sh`를 실행합니다. sponsor(4201)와 node(4101)를 띄우고(이미 떠 있으면 그대로 씀), Cloudflare 터널을 연 뒤 `open https://lejuho.github.io/Veilance/?api=…&mode=live` 링크를 출력합니다. 터미널에 `node: ready`가 나오면 준비된 것입니다.
3. 출력된 링크를 엽니다. 상단에 초록 점과 **노드 준비됨**이 보이면 라이브입니다. 로그인은 시연 계정 버튼이 아니라 관리자에게 받은 API 키로 합니다.
4. 거래 하나가 30~70초 걸리므로 그동안 설명할 거리를 준비해 둡니다.

- 터널 주소는 실행할 때마다 바뀝니다. 바뀐 주소는 링크의 `?api=`로 넘기거나, 연결 실패 화면의 **노드 주소** 칸에 넣으면 됩니다. 브라우저가 마지막 주소를 기억합니다.
- 시연 중 노드가 멈추면 상단의 **프론트 데모로 전환**을 누릅니다. 돌아올 때는 노란 띠의 **라이브 노드 연결**을 누릅니다. 전환하면 로그인이 풀립니다(두 모드의 API 키가 다름).
- `TUNNEL=ngrok scripts/live-demo.sh`는 ngrok 계정의 고정 도메인을 씁니다. 같은 도메인이 다른 곳에서 이미 켜져 있으면 `ERR_NGROK_334`로 실패합니다.
